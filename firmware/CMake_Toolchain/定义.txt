Code - 程序源码
	Library - 标准库文件
	User - main.c等文件
	Hardware - 驱动外设的头文件和c文件
	System - 延时函数等系统文件
	Start - 启动文件
build - 生成文件，在命令行执行FlashSTM32烧录
Source - STM32F103的寄存器文件
Project - MDK和CMake两种版本的项目配置文件，其中CMake文件中包含了分区表
CMakeLists.txt - CMake的配置文件
.vscode - 代码编辑器读取C源文件和编译器的配置文件

-如果原来的项目是Keil项目，请把替换文件覆盖到项目文件夹即可
